# Data Inventory

## Project
Supply-Chain Data Lake

## Use Case
E-commerce Supply Chain

This document records the source files used in the project and their role in the Data Lake.

| File | Rows | Columns | Purpose |
|---|---:|---:|---|
| `DataCoSupplyChainDataset.csv` | 180,519 | 53 | Main e-commerce supply-chain transaction data |
| `DescriptionDataCoSupplyChain.csv` | 52 | 2 | Data dictionary containing field names and descriptions |
| `tokenized_access_logs.csv` | 469,977 | 8 | Web/access activity data containing product, category, date, time, department, IP and URL information |

## 1. DataCoSupplyChainDataset.csv

### Structure

- Rows: 180,519
- Columns: 53
- Grain: One order-item/transaction record per row

### Main Data Categories

- Customer information
- Order information
- Order-item information
- Product information
- Category and department information
- Shipping and delivery information
- Geographic information
- Sales, discount and profit information

### Important Fields

`Customer Id`, `Order Id`, `Order Item Id`, `Product Card Id`, `Category Id`, `Department Id`, `Order Date`, `Shipping Date`, `Shipping Mode`, `Delivery Status`, `Late_delivery_risk`, `Sales`, `Order Item Quantity`

## 2. DescriptionDataCoSupplyChainDataset.csv

### Structure

- Rows: 52
- Columns: 2

### Columns

- `FIELDS`
- `DESCRIPTION`

### Purpose

This file acts as the data dictionary for the main DataCo dataset. It provides descriptions of the fields and helps the team understand the meaning of the source columns.

## 3. tokenized_access_logs.csv

### Structure

- Rows: 469,977
- Columns: 8

### Columns

- `Product`
- `Category`
- `Date`
- `Month`
- `Hour`
- `Department`
- `ip`
- `url`

### Purpose

This file contains web/access activity related to products and categories. It may be used as an additional data source for future analysis after its relationship with the main supply-chain dataset is validated.

## Raw Data Policy

All three source files are stored in the `datalake/raw/` layer in their original form.

Raw files must not be manually edited, cleaned, renamed internally, or overwritten.

Any cleaning, transformation, deduplication, type conversion or aggregation will be performed in later pipeline stages and stored in the `processed/` or `curated/` layers.

## Data Classification

### Real Source Data
Data directly obtained from the DataCo source files.

### Derived Data
Data calculated or transformed from real source data during ETL and analytics processing.

### Synthetic Data
Additional data generated by the project team for entities not available in the original source, such as warehouses, suppliers or inventory, if these are required later.

Synthetic data will always be clearly identified and will never be presented as original DataCo data.
