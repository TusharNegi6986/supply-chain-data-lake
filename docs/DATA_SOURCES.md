# Data Sources

## Project
Supply-Chain Data Lake

## Use Case
E-commerce Supply Chain

## Primary Data Source

### DataCo Smart Supply Chain for Big Data Analysis

Source: Kaggle

The main dataset contains e-commerce supply-chain transaction data including customers, orders, order items, products, shipping, delivery, financial, and geographical information.

### Files

| File | Purpose |
|---|---|
| `DataCoSupplyChainDataset.csv` | Main supply-chain transaction data |
| `DescriptionDataCoSupplyChain.csv` | Data dictionary and field descriptions |
| `tokenized_access_logs.csv` | Web/access activity data |

## Data Handling Policy

The files in `datalake/raw/` are kept in their original form.

Raw files are not manually edited, cleaned, or transformed.

Cleaning and transformation will be performed in later pipeline stages and stored in the `processed/` and `curated/` layers.

## Data Classification

### Real Source Data
Data directly obtained from the DataCo dataset.

### Derived Data
Data calculated or transformed from the source data during the ETL and analytics processes.

### Synthetic Data
Additional data generated by the project team when required for entities that are not available in the original dataset. Synthetic data will always be clearly labelled.
